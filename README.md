# Lazy Daily для Windows

Скрипт автоматизирует ежедневную работу с ZIP-архивами: отслеживает папку `Downloads`, распаковывает новый архив в отдельную папку задачи, открывает папку с файлами, выделяет нужные файлы для загрузки и открывает `.docx`-документ.

Скрипт написан на PowerShell и предназначен для Windows 11.

## Что делает программа

После запуска скрипт постоянно ожидает появления нового ZIP-архива в папке загрузок пользователя:

```text
C:\Users\<UserName>\Downloads
```

Когда появляется новый `.zip`, программа:

1. Находит самый новый ZIP-архив в папке `Downloads`.
2. Ждёт, пока архив полностью скачается.
3. Создаёт новую папку задачи в директории:

```text
C:\Users\<UserName>\Documents\Daily
```

Папки создаются по порядку:

```text
Задача_1
Задача_2
Задача_3
```

4. Распаковывает ZIP-архив в созданную папку.
5. Считает количество найденных `.geojson` и `.docx` файлов.
6. Открывает папку задачи в Проводнике Windows.
7. Автоматически выделяет все файлы в основной папке задачи, кроме `.docx`.
8. Открывает первый найденный `.docx`-файл.
9. Удаляет исходный ZIP-архив из `Downloads`.
10. Добавляет путь к обработанному архиву в историю, чтобы не обрабатывать его повторно.
11. Продолжает ожидать следующий ZIP-архив.

## Важное ограничение

Windows Explorer может автоматически выделять только те файлы, которые лежат прямо в открытой папке.

Если `.geojson`-файлы находятся внутри подпапок архива, они не будут визуально выделены в основной папке задачи. Скрипт их найдёт и посчитает, но выделить сможет только файлы, лежащие непосредственно в папке `Задача_N`.

Файл `.processed_archives.txt` хранит историю уже обработанных архивов.

## Установка

### 1. Скачайте файл скрипта

Поместите файл, например, сюда:

```text
C:\Scripts\lazy_daily_v2.ps1
```

Если папки `C:\Scripts` нет, создайте её вручную.

### 2. Разрешите запуск PowerShell-скриптов

Откройте PowerShell от имени обычного пользователя и выполните команду:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Если PowerShell попросит подтверждение, введите:

```text
Y
```

Эта команда разрешает запуск локальных PowerShell-скриптов для текущего пользователя.

## Запуск

Разрешите системе запускать скрипт:

```powershell
Unblock-File -Path "C:\Scripts\lazy_daily_v2.ps1"
```

Запустите скрипт командой:

```powershell
& "C:\Scripts\lazy_daily_v2.ps1"
```

После запуска в консоли появится сообщение:

```text
Скрипт запущен.
Папка загрузок: C:\Users\<UserName>\Downloads
Папка задач: C:\Users\<UserName>\Documents\Daily
Ожидаю новый ZIP-архив...
```

Теперь можно скачивать ZIP-архивы. Скрипт автоматически обработает каждый новый архив.

## Создание ярлыка на рабочем столе

Скрипт можно запускать не только через PowerShell-команду, но и через ярлык на рабочем столе.

### 1. Создайте ярлык

Нажмите правой кнопкой мыши на рабочем столе и выберите:

```text
Создать → Ярлык
```

В поле **«Укажите расположение объекта»** вставьте команду:

```text
powershell.exe -ExecutionPolicy Bypass -NoExit -File "C:\Scripts\lazy_daily_v2.ps1"
```

Нажмите **Далее**.

### 2. Назовите ярлык

Например:

```text
Lazy Daily
```

Нажмите **Готово**.

Теперь скрипт можно запускать двойным кликом по ярлыку.

### 3. Установите иконку для ярлыка

Чтобы заменить стандартную иконку:

1. Нажмите правой кнопкой мыши по ярлыку.
2. Выберите **Свойства**.
3. Нажмите **Сменить значок**.
4. Нажмите **Обзор**.
5. Выберите файл иконки в формате `.ico`.
6. Нажмите **ОК** → **Применить**.

Для ярлыка Windows лучше использовать именно файл `.ico`, а не `.png` или `.svg`.

### Важно

Ярлык нужно создавать не на сам файл `.ps1`, а именно на команду запуска через PowerShell.

Если создать ярлык напрямую на `.ps1`, Windows может просто открыть код скрипта в редакторе, а не запустить программу.

## Как остановить программу

Чтобы остановить скрипт, нажмите в окне PowerShell:

```text
Ctrl + C
```

## Настройки

В начале файла есть несколько параметров, которые можно изменить.

### Автоматическое открытие DOCX

```powershell
$OpenDocxAutomatically = $true
```

Если оставить `$true`, скрипт будет автоматически открывать первый найденный `.docx`.

Если Word или другая программа открывается долго, можно поставить:

```powershell
$OpenDocxAutomatically = $false
```

Тогда скрипт будет только открывать папку задачи и выделять файлы, а `.docx` можно будет открыть вручную.

### Скорость проверки новых архивов

```powershell
$NoZipCheckDelayMs = 1200
```

Это интервал проверки папки `Downloads`, если новых архивов нет.

Значение указано в миллисекундах.  
`1200` означает примерно 1.2 секунды.

### Ожидание завершения загрузки ZIP

```powershell
$DownloadCheckDelayMs = 500
```

Это интервал проверки, докачался ли ZIP-архив.

### Пауза перед выделением файлов в Проводнике

```powershell
$ExplorerDelayMs = 350
```

Это пауза после открытия Проводника перед автоматическим выделением файлов.

Если файлы иногда не выделяются, можно увеличить значение, например:

```powershell
$ExplorerDelayMs = 700
```

## Кодировка

Скрипт содержит русский текст, поэтому файл должен быть сохранён в кодировке:

```text
UTF-8 with BOM
```

Если в PowerShell вместо русского текста появляются непонятные символы, откройте файл в VS Code и выполните:

```text
Save with Encoding → UTF-8 with BOM
```

Также рекомендуется запускать скрипт через Windows Terminal или PowerShell 7.

## Что делать, если скрипт не запускается

### Ошибка: running scripts is disabled

Выполните:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Затем снова запустите скрипт.

### Появляются непонятные символы вместо русского текста

Проверьте, что файл сохранён как `UTF-8 with BOM`.

Также можно использовать Windows Terminal вместо старого окна PowerShell.

### Файлы не выделяются автоматически

Попробуйте увеличить паузу:

```powershell
$ExplorerDelayMs = 700
```

Если файлы лежат внутри подпапок, Windows Explorer не сможет выделить их из основной папки задачи.

### DOCX открывается слишком долго

Отключите автоматическое открытие документа:

```powershell
$OpenDocxAutomatically = $false
```

## Рекомендуемый сценарий работы

1. Запустить PowerShell или ярлык на рабочем столе.
2. Скачать ZIP-архив.
3. Дождаться, пока скрипт создаст папку задачи.
4. В открывшемся Проводнике перетащить выделенные файлы в нужную загрузку.
5. При необходимости посмотреть открытый `.docx`.
6. Продолжить работу со следующим архивом.

# Версия для Linux (Bash)

Скрипт `lazy_daily_linux.sh` делает то же самое, но для окружения Linux (KDE/Plasma с `dolphin` и `mostechoffice`).

## Что делает

- Отслеживает появление новых `.zip` в `~/Загрузки`
- Ждёт завершения загрузки (размер файла стабилизируется)
- Создаёт папки `~/Daily/Задача_1`, `Задача_2` и т.д.
- Распаковывает архив
- Удаляет исходный `.zip`
- Логирует обработанные архивы в `~/.lazy_daily_processed.log`
- Открывает папку задачи в `dolphin`
- Открывает первый найденный `.docx` через `mostechoffice`
- Выводит количество найденных `.geojson`

## Установка

1. Поместите скрипт, например, в `~/bin/lazy_daily_linux.sh`
2. Сделайте исполняемым:

```bash
chmod +x ~/bin/lazy_daily_linux.sh
```

Добавьте алиас в ~/.bashrc или ~/.zshrc

```bash
alias lazyd='~/bin/lazy_daily_linux.sh'
```

## Запуск

```bash
lazyd
```
Остановка — Ctrl+C.

## Зависимости
- dolphin (файловый менеджер KDE)

- mostechoffice (для открытия .docx)

- unzip, find, stat, grep

Если у вас другой файловый менеджер или офисный пакет — замените команды в скрипте.

## Отличие от Windows

- Лог хранится в ~/.lazy_daily_processed.log

- Проверка завершения загрузки — по стабильности размера файла (каждые 3 секунды)

- Нет автоматического выделения файлов (только открытие папки)

При желании можно заменить `dolphin` на `nautilus`, `thunar` или `pcmanfm`, а `mostechoffice` — на `libreoffice`.
